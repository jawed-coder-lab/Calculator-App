# CLI Calculator (Python) 🧮

A simple, clean, and object-oriented calculator that runs right in your terminal. It automatically saves your calculation history to a text file so you don't lose your data after closing the app.

## 🚀 Features
* *Core & Essential Math:* Addition, subtraction, multiplication, division, power, modulo, and square root.
* *Auto-Save:* Your calculation history is safely stored in a local history.txt file.
* *Crash-Proof:* Handles typos, invalid inputs (like letters), and division-by-zero errors without crashing.

## 🛠️ How to Run
Just make sure you have Python 3 installed, open your terminal, and run:

bash
python calculator.py


## 📂 File Structure
* calculator.py: The main script file.
* history.txt: Automatically created after your first calculation to keep track of your history.
